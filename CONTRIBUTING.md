# Contributing

Перед pull request создайте issue с описанием изменения. Для торговой логики
отдельно перечислите меняющиеся сигналы, параметры риска и ожидаемое поведение.

Запустите `ruff check .`, `pytest --disable-socket -q` и `python -m build`.
Никогда не прикладывайте реальные `.env`, логи, сделки, снимки счетов или
идентификаторы. Изменения, ослабляющие paper-default и live-gates, не принимаются.
